Tropeamine Face Library

Turn character cards into reusable face references. Your images stay on this device.

01 / Add cards

Add one or more cards. For mixed-character batches, assign a character to each card below before scanning. You can reassign any face afterward.

Automatic and manual crops use a 4:5 portrait frame at source resolution. Original crops are preserved. Optional enhancement is available in the gallery.

02 / Review card

Drag on the card to select a face area. Your selection becomes a 4:5 crop without stretching or upscaling. Use Edit Crop on a gallery image to replace its existing crop.

03 / Reference gallery (0)

Check each crop, rename it, or delete it. Assign or correct each face’s character. The ZIP includes a folder per character; unassigned faces go into Unsorted.

Optional AI enhancement

Enhance a copy after cropping. Start with 2× and compare eyes, nose, lips and freckles before using it. AI can change small details; it cannot recover missing identity information. No face restoration or beautification is used.

Lower blend keeps more of the normally resized source. 0% uses ordinary resizing. Model tools and weights download on first use; your crop stays on this device. Large results are limited to 8 MP / 4096 px per side.

Settings apply to the next Enhance action. Original downloads always use the source crop. ZIP exports include originals and any enhanced copies in a separate enhanced folder. Gallery contents last until you refresh.
